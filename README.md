AutoDelete takes care of the repetitive parts of looting so you don't have to.  
Quickly mark items to delete, sell, or keep, apply rules based on rarity or item level, and let the addon handle the rest while you play.

## Features

- Drag-and-drop **Delete**, **Sell**, and **Keep** lists with built-in search
- Integrates with **ElvUI bag frame**, adding 2 quick buttons to instantly add items to Sell or Delete
- **Auto-sell at vendors** by rarity  
  <sub>Junk • Green • Blue • Epic with optional iLvl range</sub>
- **Auto-repair**, with optional guild bank usage
- **Summon Scavenger** companion automatically at the Goblin Merchant
- **Hide Greedy Scavenger** chat and emote spam
- **Auto-invite** on whisper keyword with loot rules and raid conversion options
- **Per-character tracking**  
  <sub>Gold earned • items sold/deleted • repairs • inventory average</sub>
- **Profile tools**  
  <sub>Copy from alts • import lists • clear lists • remove junk/sellable items</sub>
- **Shift-click any item** to quickly search for it in your lists

## Installation

1. Download the latest `zip` from the [Releases](https://github.com/disarrayed/AutoDelete/releases) page  
2. Extract to your `WoW\Interface\AddOns` folder  
3. **Important:** Folder must be named `AutoDelete`  
   <sub>If it shows `AutoDelete-main`, rename it</sub>  
4. **Restart WoW**  
   <sub>`/reload` is not enough for a fresh install</sub>

## Slash Commands

- `/del` — open settings
- `/del clean` — remove duplicates across Delete and Sell lists
- `/sellgreens` — manually sell green gear at a vendor

## About

AutoDelete is built for Project Ebonhold (Wrath 3.3.5a) to simplify inventory management without changing gameplay.
